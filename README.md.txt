# AI-Powered Career & Interview Assistant

## Overview
This project is an AI-based interview evaluation system that analyzes:
- Semantic correctness of answers
- Speech confidence (pauses, fillers, pace)
- Generates automated human-readable feedback

## Features
- Interview question generation
- Live audio interview evaluation
- Whisper-based speech-to-text
- Sentence-transformer semantic scoring
- Confidence-aware final scoring
- AI-generated feedback
- Job recommendation (future scope)

## Tech Stack
- Python
- Flask
- Whisper
- Sentence Transformers
- Librosa
- HTML

## How to Run
1. Activate virtual environment  
   `.venv\Scripts\activate`

2. Install dependencies  
   `pip install -r requirements.txt`

3. Start server  
   `python server.py`

4. Open browser  
   `http://127.0.0.1:5000`

## Viva Explanation (Short)
The system evaluates interview performance by combining semantic similarity of answers with speech confidence metrics like pauses and filler words, and generates automated feedback for improvement.
